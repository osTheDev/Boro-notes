# Boro Notes

A notes and garment pattern-sketching app built for the Galaxy Z Fold 8. The cover screen shows one pane at a time. The inner screen shows your notes and the open note side by side.

## Installing on your phone

Every push to `main` builds the app and publishes it on the [Releases page](../../releases). Open the newest release on your phone and tap the `.apk` file to install it. Each pull request also gets a **Test build for PR #N** release, so you can try a change before merging it.

Every build is signed with the same key, so a new one installs over the old one and keeps your notes.

## Checkpoints

1. **Notes base**: create, edit, search and delete notes, with autosave and a layout that adapts to the cover and inner screens.
2. **Pattern making**: a finger-friendly garment sketch canvas with snap-to-grid, auto-straighten and fill tools; sketches linked to notes; a development tracker for ideas.
3. **Utilities**: checklists, quick capture from the cover screen, tabletop (half-folded) mode, export and backup.
